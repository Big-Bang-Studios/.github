# Big Bang Studios README.md
Hello, Big Bang Studios is a team created by **Logan Baez**, our main project is [VAII](https://vaii-two.vercel.app).
VAII (Virtual Assistant with Internet Integrations) is an app with 70+ integrations total, 50+ APIs included, 20+ Native integrations.
You can find the VAII GitHub at https://github.com/Big-Bang-Studios/VAII.
VAII is our only project that we are maintaining, we hope we can host a ton of other apps under **Big Bang Studios**.
